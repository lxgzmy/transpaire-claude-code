How to use Claude with the Transpire Z: drive

Ask about the Z: drive in normal words and Claude will find files, tell you where to save things, and spot duplicates. No commands to learn.

Everyday guide · Transpire staff

Built for Transpire specifically. Claude has been taught Transpire’s own filing structure — the regions (Gunnedah, SEQ, Sydney, Tamworth, Cudgen), how job numbers are formed, every folder in the LOT MASTER FOLDER template, and which folders are off limits. It is not guessing at where things go.

Start here — three steps

  • 1
    Open Claude Desktop and start a task On your computer.
  • 2
    Attach the folder Z:\PROJECTS with the folder picker.
  • 3
    Type your question in normal words.

Steps 1 and 2 take about five seconds each time. It must be On your computer — a cloud task cannot see Z:.

The four things people ask for

1

Find a file

When you know it exists but not where it is.

Say something like
  • “where’s the latest variation for 26049?”
  • “find the contract for lot 5 pearson street”
  • “has 26049 got a BASIX report yet?”
  • “show me everything in the COUNCIL folder for 26049”

You get back: the full folder path, ready to paste into the address bar in File Explorer.

Tip: the job number works better than the address — street names are spelled and punctuated differently across folders.

2

Work out where to save something

When you have a file in hand and don’t want to guess.

Say something like
  • “where should I save a signed colour selection for 26049?”
  • “I’ve got a supplier quote for 26049 — which folder?”
  • “where do council insurance certificates go?”

You get back: one recommended folder, plus how to name the file so it matches the ones already in there.

Tip: if nothing fits properly it will say so rather than invent a new folder. Treat that as a real answer worth raising with someone.

3

Check for duplicates and clutter

When a folder has got messy, or you’re not sure which copy is real.

Say something like
  • “any duplicate files in the Gunnedah jobs?”
  • “is there more than one copy of the contract for 26049?”
  • “anything filed in the wrong place in 26049?”

You get back: a short grouped list of what it found and what it suggests doing. Nothing is moved or deleted — it only reports.

4

Create a new folder

Say something like
  • “set up the folder tree for new job 26056 in Gunnedah”
  • “create a VAR-002 folder for 26049”

You get back: the exact plan first — what it will create and where — then it waits for you to say yes.

New jobs are always built by copying the region’s 00000 - LOT MASTER FOLDER template, never assembled by hand, so every job ends up the same shape.

What it will never do

  • Never move, rename or delete anything without showing you the exact list first and waiting for a yes.
  • Never overwrite an existing file. If something is already there, it stops and asks.
  • Never open the company passwords folder, or any certificate or key file.
  • Never get around a permission. It sees exactly what you see — if you can’t open a folder in Explorer, neither can it.

Saying “yes” to one thing does not approve the next one. It asks every time.

Getting good answers
Do thisWhy it helps
Give the job numberMore reliable than an address
Say what kind of document it is“Signed variation” beats “this file”
Ask follow-ups in the same chatIt remembers the job you’re on
Read what it flags as uncertain“Most recent, but I can’t tell if it’s signed” means go and check

“Latest” means most recently changed. That is a good clue, not proof it is the signed or approved version. For anything contractual or priced, open it and confirm.

If something goes wrong
ProblemFix
“I can’t see the Z: drive” The task is running in the cloud. Start it again On your computer.
“That folder isn’t attached” Attach Z:\PROJECTS with the folder picker.
Can’t find a job you know exists Finished jobs move to COMPLETED CONTRACTS, cancelled ones to CANCELLED CONTRACTS. Ask it to check those.
It won’t run a big whole-drive scan Desktop can’t do that. Ask IT to run it in Claude Code on the server.
