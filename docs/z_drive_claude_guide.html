How to use Claude with the Transpire Z: drive

Ask about the Z: drive in normal words and Claude will find files, tell you where to save things, and spot duplicates. Job folders and department folders alike. No commands to learn.

Everyday guide · Transpire staff

Built for Transpire specifically. Claude has been taught Transpire’s own filing, not filing in general: the regions (Gunnedah, SEQ, Sydney, Tamworth, Cudgen), how job numbers are formed, every folder in the LOT MASTER FOLDER template, and every department folder from ACCOUNTS through to WORKPLACE HEALTH AND SAFETY. It carries an index of about seventy document types — variations, SWMS, Form 2s, credit applications, toolbox talks, put and call contracts — each mapped to the folder Transpire actually keeps it in. It also knows which folders are off limits. It is not guessing at where things go.

Start here — four steps

  • 1
    Open the Claude Desktop app.
  • 2
    Switch to Code mode.
  • 3
    Check the project folder is transpire-claude-code.
  • 4
    Type /z-drive-ops and your question — or just ask in normal words.

Nothing to attach and nothing to install. Code mode already sees the whole Z: drive — job folders and department folders alike — the moment the project folder is right, so there is no separate step for admin, accounts, safety or sales.

The four things people ask for

1

Find a file

When you know it exists but not where it is.

Say something like
  • “where’s the latest variation for 24025?”
  • “find the contract for lot 5 pearson street”
  • “has 24025 got a BASIX report yet?”
  • “find the blank Form 2 for fencing”
  • “where’s the current SWMS for our plumber?”
  • “which estate folder has the stage numbers for Monterea?”

You get back: the full folder path, ready to paste into the address bar in File Explorer.

Tip: the job number works better than the address — street names are spelled and punctuated differently across folders. If a job seems to be missing, it has probably been handed over or cancelled and moved out of the live region folder. Claude checks those folders too.

2

Work out where to save something

When you have a file in hand and don’t want to guess.

Say something like
  • “where should I save a signed colour selection for 24025?”
  • “I’ve got a supplier quote for 24025 — which folder?”
  • “where does a new subbie’s certificate of currency go?”
  • “where do I file a signed marketing agreement?”
  • “where does a blank handover form live?”

You get back: one recommended folder, plus how to name the file so it matches the ones already in there.

Say whether it is blank or filled in. This is the single best thing you can do for a right answer. Blank templates live in PROCEDURES & FORMS; the completed version lives with its job or its department. A variation, a contract, a colour scheme, a SWMS, a safety pack and a QA form each have more than one correct home, so Claude will ask if your wording does not make clear which one you have.

Tip: if nothing fits properly it will say so rather than invent a new folder. Treat that as a real answer worth raising with someone.

3

Check for duplicates and clutter

When a folder has got messy, or you’re not sure which copy is real.

Say something like
  • “any duplicate files in the Gunnedah jobs?”
  • “is there more than one copy of the contract for 24025?”
  • “anything filed in the wrong place in 24025?”
  • “how messy is the top of the SALES folder?”

You get back: a short grouped list of what it found and what it suggests doing. Nothing is moved or deleted — it only reports.

It works one folder at a time and tells you which one it checked, then offers to do the next. Ask for a job, a region or a department folder rather than the whole drive. A common thing it finds is files dumped at the top of a folder instead of inside a subfolder, which is why nobody else can find them.

4

Create a new folder

Say something like
  • “set up the folder tree for new job 26056 in Gunnedah”
  • “create a VAR-027 folder for 24025”

You get back: the exact plan first — what it will create and where — then it waits for you to say yes.

New jobs are always built by copying the region’s 00000 - LOT MASTER FOLDER template, never assembled by hand, so every job ends up the same shape. There are templates for a new sales package and a new estate too, and Claude will point you at the right one to copy. It also checks the job number is not already in use, including in the handed over and cancelled folders.

What it will never do

  • Never move, rename or delete anything without showing you the exact list first and waiting for a yes.
  • Never overwrite an existing file. If something is already there, it stops and asks.
  • Never open the company passwords folder, or any certificate or key file.
  • Never get around a permission. It sees exactly what you see — if you can’t open a folder in Explorer, neither can it.

Saying “yes” to one thing does not approve the next one. It asks every time.

What it can and can’t do
Ask it thisNot this
“Find the variations for job 24025” “Find the variation that mentions the retaining wall” — it searches file names and folders, not the words inside documents. It can open a particular file once it has found it, if you ask.
“Where are the plans for this job?” “What’s in this Archicad drawing?” — CAD files (.pln, .dwg and similar), Outlook .msg files and older .doc files can be located by name but not opened. Most of DRAFTING is this kind of file.
“Check job 24025 for duplicates” “Check the whole drive” — it works through one job, region or department folder at a time and tells you which one it did.
Anything in the folders on this page Z:\SOFTWARE and Z:\CLAUDE CODE — software certificates, licences and manuals, and the automation project itself, are not handled here. Ask IT.
If something goes wrong
ProblemFix
“I can’t see the Z: drive” Check the project folder is transpire-claude-code and that Z: is actually mapped and connected on that computer — it is almost always one of those two.
It says it cannot see a department folder That shouldn’t happen in Code mode — it sees the whole drive, not just job folders. If it does, say so and treat it as a fault to report, not something to work around.
It says you don’t have access to a folder That is the real answer, not a fault. Z:\OPERATIONS is one nobody can currently open. Ask IT if you need it.
Can’t find a job you know exists Finished and cancelled jobs move out of the live region folder. Sydney uses HANDED OVER, SEQ uses ARCHIVE-HANDED OVER, and every region has a CANCELLED. Older jobs sit in COMPLETED CONTRACTS or CANCELLED CONTRACTS. Most job folders are in one of these and Claude checks them all, so give it the job number.
It won’t scan the whole drive Nothing can: the drive is about 1,700 GB. Claude checks one job, region or department folder at a time and tells you which one. To compare across the whole drive, ask IT to schedule it in Claude Code on the server.
